# Portfolio Professionnel & Innovant 🚀

Un portfolio moderne et responsive avec des animations fluides et un design professionnel.

## ✨ Fonctionnalités

- **Design Moderne** : Interface élégante avec dégradés et animations
- **Mode Sombre/Clair** : Basculez entre les thèmes selon vos préférences
- **Responsive** : Parfaitement adapté à tous les écrans (mobile, tablette, desktop)
- **Animations Fluides** : Effets de parallaxe, compteurs animés, barres de progression
- **Sections Complètes** :
  - Hero avec animation de texte
  - À propos avec statistiques
  - Compétences avec barres de progression
  - Projets avec filtres dynamiques
  - Timeline de parcours
  - Formulaire de contact
- **Performance Optimisée** : Code léger et rapide

## 🎨 Technologies Utilisées

- HTML5
- CSS3 (Variables CSS, Flexbox, Grid, Animations)
- JavaScript Vanilla (ES6+)
- Font Awesome (Icônes)

## 🚀 Installation

1. Clonez ou téléchargez ce repository
2. Ouvrez `index.html` dans votre navigateur
3. C'est tout ! Aucune dépendance à installer

## 📝 Personnalisation

### Modifier les informations personnelles

1. **index.html** : Remplacez les textes par vos informations
   - Nom, titre, description
   - Projets et leurs détails
   - Parcours professionnel
   - Coordonnées de contact

2. **styles.css** : Personnalisez les couleurs
   ```css
   :root {
       --primary-color: #6366f1;    /* Couleur principale */
       --secondary-color: #8b5cf6;  /* Couleur secondaire */
       --accent-color: #ec4899;     /* Couleur d'accent */
   }
   ```

3. **script.js** : Modifiez les titres animés
   ```javascript
   const titles = [
       'Votre Titre 1',
       'Votre Titre 2',
       'Votre Titre 3'
   ];
   ```

### Ajouter vos images

Remplacez les placeholders par vos vraies images :
- Photo de profil dans la section Hero
- Image dans la section À Propos
- Images de projets

### Configurer le formulaire de contact

Pour rendre le formulaire fonctionnel, vous pouvez utiliser :
- **FormSpree** : Service gratuit pour formulaires
- **EmailJS** : Envoi d'emails via JavaScript
- **Backend personnalisé** : Node.js, PHP, etc.

## 🎯 Sections du Portfolio

1. **Accueil (Hero)** : Présentation avec animation de texte et liens sociaux
2. **À Propos** : Description et statistiques animées
3. **Compétences** : Catégories de compétences avec barres de progression
4. **Projets** : Grille de projets avec filtres (Web, Mobile, Design)
5. **Parcours** : Timeline interactive de votre expérience
6. **Contact** : Formulaire et informations de contact

## 🌟 Fonctionnalités Avancées

- **Intersection Observer** : Animations au scroll
- **Smooth Scrolling** : Navigation fluide entre sections
- **Filtres de Projets** : Système de filtrage dynamique
- **Compteurs Animés** : Statistiques qui s'animent à l'apparition
- **Effet Parallaxe** : Arrière-plan animé dans le Hero
- **Navigation Active** : Mise en surbrillance de la section active
